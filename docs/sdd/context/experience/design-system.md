# 体验基线 · 清透紫

## 色彩角色

| 角色 | 用途 | 原则 |
| --- | --- | --- |
| 冷白 | 页面底与主要表面 | 承担大面积阅读空间 |
| 浅蓝灰 | 次级表面、分区、禁用态 | 只表现层级，不抢内容 |
| 墨黑 | 标题、重点数据、深色任务区 | 用于信息锚点 |
| 清华紫 | 主行动、当前状态、链接、关键强调 | 小面积且有明确语义 |
| 语义色 | 成功、风险、错误 | 仅用于状态，不用作内容分区主题 |

## 组件语言

- 圆角：主容器与任务区可较大；标签、按钮更紧凑。
- 边框：以低对比细边界分层，避免阴影与描边同时过重。
- 卡片：当前任务可为主卡；资料、概念、提示为轻卡，不能所有卡片同权。
- 动效：仅保留任务进行中、提交中等反馈；取消装饰性大范围发光。
- Focus：键盘焦点使用清晰的紫色外框，不能只依靠颜色变化。

## 页面优先级

学生页优先级恒为：当前状态 → 下一步行动 → 完成所需证据 → 辅助资源。
