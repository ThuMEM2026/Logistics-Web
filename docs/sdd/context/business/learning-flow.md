# 教学业务上下文

## 学生主路径

1. 从身份入口进入学生端。
2. 在课程周历识别当前周（当前为 Week 8）。
3. 在教学周详情阅读目标、概念、材料与任务。
4. 通过练习/地图建立对规则的理解。
5. 提交作业文件，完成预检与在线仿真。
6. 发起 AI 批改，阅读证据链与修改建议。
7. 回到提交或学习页面修改方案。

## Week 8 的不可丢失要素

- 仓内分拣专项练习；
- sorting wave ≤ 80 carts 等硬约束；
- 文件提交与预检；
- 在线仿真；
- AI 批改与证据反馈；
- 相关学生共创资源。

## 教师主路径

教师通过学情看板观察提交、评分与共性错误，再进入案例、变量、AI 复核、共创审核与评分规则页面进行教学运营。
