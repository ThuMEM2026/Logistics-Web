# 可复用模式

## Current-task frame

适用：课程周历、教学周详情、提交页。

- 左侧：任务名称、进度、下一行动；
- 右侧：必要状态或关键约束；
- 下方：完成任务所需的步骤与证据；
- 次要资源放在主任务之后，不与主行动竞争。

## State ladder

适用：文件提交、仿真、AI 批改。

以固定顺序展示：`准备 → 预检 → 仿真 → 批改 → 修改`。每一阶段都有一个当前动作、完成信号和失败原因，避免把所有操作按钮同时堆出。

## Semantic status

状态色必须映射到明确含义：紫=当前/行动，绿=通过，黄=风险，红=失败。不能借状态色充当课程方向或普通装饰。
