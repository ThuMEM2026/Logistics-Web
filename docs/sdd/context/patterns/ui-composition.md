# 可复用模式

## Current-task frame

适用：课程周历、教学周详情、提交页。

- 左侧：任务名称、进度、下一行动；
- 右侧：必要状态或关键约束；
- 下方：完成任务所需的步骤与证据；
- 次要资源放在主任务之后，不与主行动竞争。

## State ladder

适用：文件提交、仿真、AI 批改。

以固定顺序展示：`准备 → 预检 → 仿真 → 批改 → 修改`。每一阶段都有一个当前动作、完成信号和失败原因，避免把所有操作按钮同时堆出。

## Semantic status

状态色必须映射到明确含义：紫=当前/行动，绿=通过，黄=风险，红=失败。不能借状态色充当课程方向或普通装饰。

## Attempt-question-evidence loop

适用：需要培养问题意识的教学任务页。

- 第一屏先给出一次可执行的初步尝试，不把游戏或资料作为主入口；
- AI 入口要求学生说明已有选择、约束与卡点，并明确不直接代做；
- 学习资源只服务于当前问题；
- 预检、仿真和批改输出作为可复核证据，导向下一次修改。

## Compact navigation

适用：学生端与教师端的移动壳层。

- 品牌与身份控件保持收缩，导航横向单行滚动；
- 不让导航链接折成两行，也不让页面产生横向溢出；
- 退出等低频操作在小屏仅保留图标和可访问名称。
